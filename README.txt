SEGA FC CASH FLOW — PETUNJUK
1. Untuk tes cepat, buka index.html di browser. Beberapa fitur PWA/install dan offline membutuhkan hosting HTTPS.
2. Untuk menjadikannya aplikasi yang bisa diinstal, unggah semua file dalam folder ini ke hosting HTTPS (misalnya GitHub Pages/Netlify).
3. Buka alamat website di Chrome Android, pilih menu ⋮ lalu "Tambahkan ke layar utama" / "Instal aplikasi".
4. Data transaksi tersimpan di browser/perangkat yang digunakan. Ekspor JSON untuk cadangan; data tidak otomatis tersinkron antar perangkat.
5. Simpan Laporan PNG/JPG mengunduh gambar ke Downloads/Unduhan. Dari aplikasi File Manager, pindahkan ke folder Dokumen bila diperlukan.
6. Cetak/PDF membuka dialog cetak browser; pilih "Simpan sebagai PDF".
